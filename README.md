# Soubor README.md slouží k zobrazení informací o projektu na GitHub stránce projektu

## Jak začít pracovat:
- Kapitán týmu "naforkuje" tento repozitář  - vpravo nahoře klikne na *fork*. Forknutý projekt si pojmenujte, jak jen chcete
- Toto vytvoří vaši vlastní kopii repozitáře v GitHubu
- Poté kapitán přizve zbytek týmu jako spolupracovníky - na GitHubu v projektu vpravo nahoře settings, nahoře v levé liště collaborators, add people
- Tým potvrdí na e-mailu pozvánku do projektu
- Nyní můžete všichni naklonovat repozitář a začít zkoumat projekt ve VS Code

## Ideální postup operací:
1. nastaveni_prostredi.md
2. rozdeleni_tymu.md
3. specifika_roli.md
